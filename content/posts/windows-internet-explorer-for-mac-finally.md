When I was using [Debian](http://www.debian.org/?ref=justhart.com) as my primary operating system I installed a very handy application called [ies4linux](http://www.tatanka.com.br/ies4linux/page/Main_Page?ref=justhart.com) which allowed me to install and run Windows-based Internet Explorer 6 and 7.

These browsers are able to run on Linux all thanks to the Open Source implementation of the Windows API called [Wine](http://www.winehq.org/?ref=justhart.com) which acts as a compatibility layer for running Windows programs. It has been very useful in the past for _checking_ websites for compatibility across the different browsers and I’ve long hoped for a [Mac OS X](http://apple.com/macosx/?ref=justhart.com) derivative…

Finally it seems some [clever person](http://mike.kronenberg.org/?ref=justhart.com) has ported this application to Mac and it’s quite aptly called [ies4osx](http://www.kronenberg.org/ies4osx/?ref=justhart.com).

[![Internet Explorer on Apple OS X](http://farm3.static.flickr.com/2221/2278793451_5d15d422ff.jpg)](http://www.flickr.com/photos/justinhartman/2278793451/?ref=justhart.com "Internet Explorer on Apple OS X by Justin Hartman, on Flickr")

Installing ies4osx was relatively simple and as with the Linux derivative it requires a [Darwin](http://en.wikipedia.org/wiki/Darwin_\(operating_system\)?ref=justhart.com)\-based installation of Wine called [Darwine](http://www.kronenberg.org/ies4osx/?ref=justhart.com). Once everything has been installed you simply open up the browser you want to test on and the results are just awesome.

[![IE6 Running on Leopard](http://farm3.static.flickr.com/2355/2279584822_d6f1f3b61a.jpg)](http://www.flickr.com/photos/justinhartman/2279584822/?ref=justhart.com "IE6 Running on Leopard by Justin Hartman, on Flickr")

ies4osx runs off [Apple’s X11](http://www.apple.com/macosx/features/x11/?ref=justhart.com) implementation and is able to install Internet Explorer versions 5, 5.5, 6.0 (SP1) and 7.0 BETA but it remains a little buggy. The stability issues all relate to the Wine implementation as I had similar stability issues using ies4linux. This is a great step for Apple users and now I can finally uninstall that dual-boot Windows XP from my MacBook Pro.
