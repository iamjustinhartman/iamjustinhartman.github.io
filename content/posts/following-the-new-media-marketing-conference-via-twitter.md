If you’re attending today’s New Media Marketing conference and are planning to Twitter from the event then I’d like to suggest that you all use [Hashtags](http://hashtags.org/?ref=justhart.com) in your twitter posts.

> Hashtags are a community-driven convention for adding additional context and metadata to your tweets. They’re like tags on Flickr, only added inline to your post. You create a hashtag simply by prefixing a word with a hash symbol: #hashtag.

Using hashtags will not only enable better twitter following for the event but it will also allow users who are not attending the conference the opportunity to watch the events unfold and using hashtags is really simple.

1\. You’ll need to follow hashtags on Twitter so that hashtags can pick your tweets up. [Visit the hashtags user](http://twitter.com/hashtags?ref=justhart.com) and click follow.

2\. When you tweet from the event add **#newmedia08** to your tweet so that hashtags picks your tweet up.

When you tweet with **#newmedia08** in your post it will automatically [appear on the newmedia08 hashtags page](http://hashtags.org/tag/newmedia08/?ref=justhart.com) which any user can follow.

Let’s try it out and see how successful hashtags could be.
