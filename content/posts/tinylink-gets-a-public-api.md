After a lengthy discussion with [Charl](http://charlvn.za.net/?ref=justhart.com) last night I got some inspiration and created a [Public API](http://tinylink.co.za/api/?ref=justhart.com) for [TinyLink](http://tinylink.co.za/?ref=justhart.com). The API can be used through a [REST](http://en.wikipedia.org/wiki/REST?ref=justhart.com) or [JSON](http://en.wikipedia.org/wiki/JSON?ref=justhart.com) request and if you’re a developer you can chose either to integrate into your application.

Charl has kindly created an example [Python script](http://tinylink.co.za/api/python_example.php?ref=justhart.com) and a PHP one will follow shortly.

I also spent some time and created an [About](http://tinylink.co.za/about.php?ref=justhart.com) page which highlights what the service is about as well as what’s on the TODO list.

Finally, I wanted to thank [Dominique](http://www.webadstudio.com/?ref=justhart.com) for doing the hard maths and working out that based on the current database structure TinyLink can hold a total of **2,176,782,336** urls. Calculators were needed!

I’m really not sure why but this project has got me very excited…
